# what-i-love

Turn Intent to Animation.

A one-page animated site: 3 ATLO capstone agents, each sketched then
assembled into a giant Tesla Model 3 shaped robot. Pure HTML/CSS/SVG —
no build step, deployed via GitHub Pages.

- [`skills/`](skills/) — one skills.md per agent, sourced from the real
  agent definitions in the Agentforce-Readiness-Capstone project.
- [`index.html`](index.html) / [`style.css`](style.css) — the page and the
  sketch → finished crossfade animation.
